Last Mile Delivery Analysis
📌 Project Overview

Last Mile Delivery Analysis is a SQL-based data analysis project focused on understanding delivery performance, customer orders, delivery zones, depots, and operational efficiency.

The project uses SQL to analyze delivery data and generate meaningful business insights.

🛠️ Tools & Technologies
MySQL
MySQL Workbench
SQL
ER Diagram
PowerPoint

📊 Key Analysis
Delivery performance analysis
Customer and order analysis
Delivery zone analysis
Depot performance analysis
Delivery time analysis
Identification of operational trends and insights

🎯 Objective
The main objective of this project is to analyze last-mile delivery operations using SQL and identify useful insights that can help understand delivery performance and operational efficiency.
